安装方式

  1. 用安卓手机打开本页，点击上方「下载 APK」。
  2. 浏览器提示"此类文件可能有害"时，选择「仍要下载」。
  3. 打开下载好的 zhiyue-v1.2.1.apk，按提示允许「安装未知应用」（仅需一次）。
  4. 安装完成后，桌面出现「指月」图标。
若使用微信内置浏览器打开，请点右上角「···」→「在浏览器打开」后再下载。

进入体验（30 秒上手）

推荐：演示模式（无需任何权限）

  1. 打开应用 → 首页任选一套法会（瑜伽焰口 / 梁皇宝忏·起忏 / 药师普佛 / 阿弥陀佛普佛）→ 保持「演示模式」→ 点「开始演示」。
  2. 应用自动播放该法会内置录音，字幕与录音由同一播放时钟推进；屏幕显示当前段落与下一段，法本按唱诵逐字点亮，已诵字变暗、当前字高亮。
  3. 点「下一段 / 上一段」可手动纠偏；点「暂停」可停下；点「结束」进入回向页。

进阶：现场模式（实验性）

  1. 首页选择「现场模式」→「开始跟诵」→ 首次会请求麦克风权限，选择「允许」。
  2. 把手机放在能听清唱诵的位置（或对着另一台播放唱诵的设备），应用会在约 1–3 秒内锁定段落并持续跟踪。
  3. 该能力仍在迭代：环境嘈杂或音色差异较大时可能跟踪不稳，建议用「下一段」手动纠偏，或直接使用演示模式。

它怎么工作

梵呗有三个结构性特征：谱本固定、唱腔稳定、段落边界清晰。因此"唱到哪儿"不必依赖通用语音识别， 而是一个音频-谱本对齐问题：端侧提取 log-mel 声学特征，与内置参考特征做带时间伸缩容差的在线匹配， 叠加单调约束与滞回锁定，得到段落与句级位置。

结果是：模型与参考特征随 APK 内置（约 2.7 MB），无需联网、无需算力服务器； 位置估计天然不回跳、不跳段。法会即一份 JSON 模板（段落、法本、参考音轨）， 后续新增《梁皇宝忏》《三时系念》或日常课诵，只需补模板与音轨，不必改代码。 v1.2.0 起，逐字时间轴由构建期 faster-whisper 识别真实音节位置生成（AI 段），端侧仍只做一次查表，不进 APK、不在端侧推理。

演示模式下，应用播放内置录音，字幕与录音共用同一播放时钟，因此逐字点亮与音频天然对齐； 这是回放同步，不是实时识别。实时识别对应「现场模式」，为实验性能力。
